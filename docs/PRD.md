# 算的准 1.0 产品需求文档

## 产品定位

“算的准”是一款面向中文用户的传统命理文化分析工具。它把出生信息、真太阳时、八字、大运流年、八宅命卦、姓名五格和合婚整理成易读的个人报告。产品定位是“传统文化参考与自我认知工具”，不做医疗、投资、法律或确定性人生承诺。

## 核心用户路径

1. 用户从首页理解产品价值与边界。
2. 点击“开始排盘”，填写姓名、性别、日期、时间、城市。
3. 生成可滚动的个人分析结果。
4. 可选填写伴侣资料，查看合婚参考。
5. 用户通过微信 `ANS_0912` 联系人工详批服务。

## 1.0 范围

- 首页品牌与价值说明
- 单人排盘
- 真太阳时开关与城市经度
- 八字、五行、大运流年、八宅、姓名五格
- 双人合婚参考
- 移动端适配、减少动效、键盘可访问

## 暂不纳入

- 在线支付与账户系统
- 自动化确定性预测
- 房屋户型图识别
- 社交媒体发布、AiToEarn 集成

## 验收标准

- 首页在桌面与手机宽度下无横向溢出。
- 首屏 1 秒内显示主要内容，动效不阻塞表单。
- 排盘页的既有计算逻辑不变。
- `prefers-reduced-motion: reduce` 下关闭非必要动画。
- 所有核心静态资源由正式域名返回 200。
- 视觉改造不改变八字计算输入和输出字段。
- 全站可键盘操作：焦点环始终可见，排盘完成后焦点进入结果区。
- 首屏关键资源与脚本总量有 gzip 体积预算，超限即挡在合并前。

> 「首屏 1 秒」「键盘可访问」不再只靠人工判断：前者由 `scripts/verify.mjs` 的
> 体积预算约束，后者由焦点环与结果区聚焦契约约束，均随 `npm run release:check` 执行。
