# 算的准 1.0 技术方案

## 当前基线

- 部署：38.76.193.254
- Web：Nginx 1.27 Alpine
- 目录：`/srv/suanzhun/public`
- 架构：无构建步骤的静态 HTML/CSS/JavaScript
- 计算模块：`bazi.js`、`analysis.js`
- 页面模块：`index.html`、`paipan.html`、`app.js`

## 选择的工作栈

当前阶段继续使用原生 HTML + CSS + JavaScript，不引入 React、构建器或额外运行时。原因是现有站点是纯静态 Nginx 部署，原生栈能降低部署风险、保持计算逻辑稳定，并支持 CSS 动效与渐进增强。

## 视觉系统

- 背景：暖白粉 `#fff8fa` 与粉雾渐变
- 主色：莓红 `#8f3656`
- 强调色：珊瑚粉 `#e97891`
- 辅助色：玉石绿 `#5e9b88`
- 纹理：CSS radial/repeating gradients + 低透明度 grain overlay
- 圆角：16–24px；阴影：低对比、偏暖色
- 动效：CSS keyframes，首屏分层 reveal、浮动 orb、卡片 hover、按钮 shine

## 工程规则

- 计算逻辑只做兼容性修复，不在视觉改造中重写。
- 所有动画必须可被系统减少动效设置关闭。
- 文案避免确定性承诺，保留传统文化参考说明。
- 修改前保留线上文件副本；发布后逐项检查首页、排盘页和脚本状态码。

## 发布策略

1. 本地副本编辑与语法检查。
2. 生成远端目录备份。
3. 只上传变更文件。
4. 检查静态资源状态码与关键字符串。
5. 用户可见验收后再继续第二轮功能开发。
