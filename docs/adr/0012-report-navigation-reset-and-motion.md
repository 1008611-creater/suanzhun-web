# ADR 0012：报告导航、重置完整性与滚动动效

- 状态：已采纳
- 日期：2026-09-18

## 背景

真实浏览器审计线上排盘页，发现三处与「产品级」不符的问题：

1. **报告太长且没有导航。** 桌面 `docHeight` 约 6800px，手机约 9500px，共 12 块卡片，
   但整站没有报告内目录，也没有「回到顶部」按钮，用户只能一路手滚。
2. **「重置」复位不完整。** 实测只清掉了姓名、日期、时间与合婚字段，
   出生地仍停在用户上次选的「河北 唐山（丰南）」，性别、时制没复位，
   合婚面板也保持展开，看起来像按钮坏了。
3. **减少动效设置下滚动仍是动画。** `prefers-reduced-motion: reduce` 时，
   CSS 只关掉了 `animation` / `transition`，管不到 `app.js` 里两处
   `scrollIntoView({ behavior: 'smooth' })`，系统设了减少动效滚动依旧平滑。

## 决策

### 1. 报告内目录与回到顶部

`app.js` 的 `render()` 里把每块卡片的创建收成 `card(title, extraCls)`：
统一编号、写入 `id`、收集目录项。渲染结束后在最前面插入 `<nav class="toc">`
目录（锚点 + 点击滚动），并在「下一步」卡片加「回到顶部」按钮。
目录与回到顶部按钮在打印样式里隐藏。

### 2. 重置走统一入口且回到初始状态

出生地默认值收敛成 `CITY_DEFAULT` + `applyDefaultCity()`，初始化与重置共用。
新增 `resetForm()`：清空姓名/日期/时间、性别与时制回到默认、出生地回到默认、
合婚面板收起、结果区隐藏并清空。

### 3. 滚动行为尊重系统设置

新增 `prefersReducedMotion()` / `scrollBehavior()` / `scrollToEl()` 三个入口，
所有程序滚动都走 `scrollToEl()`：开启减少动效时用 `behavior: 'auto'`，
否则用 `smooth`。`verify.mjs` 断言不再出现写死的 `behavior: 'smooth'`。

### 4. 写成可执行闸门

`scripts/verify.mjs` 新增三项契约：报告有目录与回到顶部入口、重置回到初始状态、
滚动行为尊重减少动效设置。契约数 56 → 59，README 同步。

## 后果

- 长报告可直接跳转到关心的段落，看完能一键回顶。
- 重置后页面与刚打开时一致，不再残留上次输入。
- 系统开启减少动效时，程序滚动不再强行平滑。
- 代价是新增 3 项契约、一处 CSS 组件与一份 ADR，README 与索引同步更新。
