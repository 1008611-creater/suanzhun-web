# ADR 0003：结果页文字对比度以令牌契约锁定

- 状态：已采纳
- 日期：2026-09-18

## 背景

用真实浏览器逐元素实测排盘结果页（`paipan.html`）后，发现 **24 处 WCAG AA 对比度不达标**，
最严重的是深色芯片上的深色文字，肉眼几乎不可见：

| 对比度 | 位置                                   | 根因                                                            |
| ------ | -------------------------------------- | --------------------------------------------------------------- |
| 1.26:1 | 八宅「伏位 / 六煞 / 祸害」             | `jClass()` 只给「大吉/吉/大凶/凶」加类，「小吉/凶」落到深底深字 |
| 1.56:1 | 五行「金 忌」                          | `WX_COLOR` 把五行原色直接当文字色                               |
| 1.91:1 | 大凶标签                               | `--xiong-strong` 是给深底用的亮色，被用在浅底                   |
| 2.73:1 | 说明文字 `.note` / `.hint` / `.footer` | `--dim2` 取到 68% 亮度，太浅                                    |

首页 `.price.hot` 还残留 `linear-gradient(180deg,#221d12,...)` 的暗金算命模板底色，与浅粉设计冲突。

## 决策

**文字色与填充色分离，并按底色分成两族令牌。**

- 浅底文字：`--gold-ink` / `--jade-ink` / `--xiong-ink` / `--xiong-strong-ink` /
  `--wx-*-ink`，全部对实际卡片底色实测 >= 4.5:1。
- 深底芯片文字：`--ink-on-dark` / `--dim-on-dark` / `--jade-on-dark` /
  `--xiong-on-dark` / `--xiong-strong-on-dark` / `--gold-on-dark`，
  对实心底 `#0f131b` 与热点底 `#301513` 双重验证 >= 4.5:1。
- `--dim2` 由 68% 调深到 51%（5.15:1）。
- 五行原色（`--wx-*`）只用于进度条填充，不再用于文字。
- 四柱天干地支的渐变端点改为 `oklch(66% .14 350)`（5.52:1）。
- 八宅「小吉」与「偏凶」补进 `jClass()` 的配色映射。

**新增 `scripts/check-contrast.mjs` 作为自动闸门**，接入 `npm run release:check` 与 CI。
它把「令牌取值 → 最坏底色 → 对比度」写成断言，并检查浅底选择器不再使用深底原色当文字色。

## 后果

- 改配色必须同时满足 `npm run contrast`，否则无法通过质量门。
- 令牌分两族后，页面内不能再随意引用裸色值；新增配色需先补令牌与断言。
- 对比度脚本用 `oklch()` → sRGB → WCAG 相对亮度自行换算，不依赖浏览器，
  因此可以在 CI 里对静态文件直接校验。
