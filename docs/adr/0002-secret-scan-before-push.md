# ADR 0002：推送前必须通过密钥扫描

- 状态：已采纳
- 日期：2026-09-17

## 背景

本仓库是独立的 GitHub 仓库（`1008611-creater/suanzhun-web`），任何提交都会离开本机。
工作区根目录的密钥扫描把 `08_其他项目` 整体排除在外，因此这个子项目在推送前
实际上没有任何凭据检查。

## 决策

在仓库内提供 `scripts/secret-scan.mjs`，扫描工作区内的文本文件，识别常见明文凭据
（各类 API Key、GitHub 令牌、JWT、私钥头、被赋值的疑似密钥）。

它被接入两处，缺一不可：

- `npm run release:check`：本地发布质量门的第一道闸。
- `.github/workflows/ci.yml`：CI 在每次推送与 PR 上执行。

命中即失败并退出非零码，同时打印文件、行号与脱敏预览。

## 后果

- 扫描脚本自身必须包含模式字面量，因此扫描时跳过自身与 `package-lock.json`。
- 占位符与测试假值通过 `PLACEHOLDER_RE` 过滤，避免误报淹没真问题。
- 扫描只覆盖文本文件且跳过二进制，不能替代人工确认；提交前仍应检查 `git diff`。
- 凭据处理方式：移到仓库外，改为运行时参数或环境变量，不写进任何文档。
