# ADR 0011：回车键提交排盘表单

- 状态：已采纳
- 日期：2026-09-18

## 背景

排盘页的表单容器是 `<div class="form">`，不是原生 `<form>`。浏览器不会给非原生表单
任何默认提交行为，所以用户填完最后一个字段顺手按回车时，页面**毫无反应**。
这是几乎所有表单的通用习惯，也是真实用户最容易踩到的一处卡顿——不是报错，
而是「按了没动静」，用户只能自己想到去点按钮。

中文输入法用回车确认候选词，因此不能简单地「按回车就提交」，否则打字打一半
就会触发排盘。

## 决策

### 1. 在表单容器上接住回车

`app.js` 新增 `bindEnterSubmit(formEl)`，对每个 `.form` 绑定 `keydown`：
按 `Enter` 时 `preventDefault()` 并调用 `run()`，与点击「开始排盘」完全同一路径。

### 2. 跳过输入法合成中的按键

命中条件里排除 `e.isComposing` 与 `keyCode === 229`（部分输入法合成结束时不带
`isComposing`，只留 229）。同时排除 `BUTTON` / `SELECT` / `TEXTAREA` 三类目标，
避免抢走按钮自身的回车激活与下拉框选择。

### 3. 写成可执行闸门

`scripts/verify.mjs` 新增两项契约：回车提交监听存在（`keydown` 监听 +
`bindEnterSubmit`），以及跳过合成中的按键（`isComposing` + `keyCode === 229`）。
契约数 54 → 56。

## 后果

- 填完表单按回车即可排盘，空表单回车仍走既有的行内提示并聚焦日期字段。
- 中文输入法打字过程不会被误触发。
- 代价是新增 2 项契约，README 同步更新。
